## 🧭 关于我

你好，我是 **熊鑫晨**（`@xxc2007`），地理科学专业在读，习惯「一个人，与 AI 一起」把念头打磨成真实上线、经得起长期访问的网页。

我的项目围绕两条线索展开：**空间里的真实世界**，与**时间里的个人记忆**。前者长成了一座原生支持中英双语、持续巡检千余公开信源的地理资讯站；后者则把高中三年的红砖楼、香樟与老水塔安放进一本永不关页的数字纪念册。三座站点均以 **MIT 协议开源**，同驻 `xxc2007.me`，彼此独立部署、长期维护。
