## 🧭 关于我

你好，我是 **熊鑫晨**（`@xxc2007`），一名地理科学专业本科生，也是一位习惯「一个人，与 AI 一起」把念头打磨成真实线上作品的独立创造者。

我关心两件事：**空间里的真实世界**，以及**时间里的个人记忆**。前者让我搭起了每天清晨八点出刊的地理资讯站，后者让我把高中三年的操场、香樟与老水塔装进了一本永不关页的纪念册。所有项目均以 **MIT 协议开源**，部署在同一个域名 `xxc2007.me` 之下，并长期由自己维护。

## 🛠 我怎么做事

1. **先想清楚它是干什么的** — 动笔写第一行代码前，先用一句话写明这一页要替读者解决什么问题。
2. **克制而彻底的工程取舍** — 静态纪念册与个人主页坚持零框架、无构建步骤与本地自托管资源；需要持续采集与推理的内容管线则交由 TypeScript + PostgreSQL + 队列稳健运转。
3. **地图与地理表达亲手打磨** — 从 NASA Blue Marble 球面贴图、MapLibre 多源卫星图层到空间显著性评分，让地理视角贯穿在每一像素里。
4. **上线，并且长期养着它** — 写下校验脚本、部署基线与回归测试，确保同域名下的三个站点与评论服务互不干扰、长久可访问。
